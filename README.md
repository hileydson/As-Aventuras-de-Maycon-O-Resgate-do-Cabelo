As Aventuras de Maycon - O Resgate do Cabelo

Esse game é uma continuação de um projeto que tentei na minha adolescencia, sempre quis completar esse projeto e estou realizando esse desejo agora com essa release.

Toda a arte e história são baseados nos meus amigos e na história que criamos quando eramos ainda adolescentes.

Se trata de um game que mistura varios estilos de jogo, assim como plataforma 2d, 3d, FPS, suspense, comedia, puzzle, entre outras mecanicas que deixa o jogo diversificado.

É uma carta de nostalgia da nossa adolescencia.
