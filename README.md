Essa é a demo do jogo 'As Aventuras de Maycon - O Resgate do Cabelo'.

Esse game é um continuação de um projeto que tentei na minha adolescencia, gostaria muito de fazer pelo menos uma demo dele e estou realizando esse desejo que sempre tive.

Toda a arte e história são baseados nos meus amigos.

Se trata de um game que mistura varios estilos de jogo, assim como plataforma.
É uma carta de nostalgia da nossa adolescencia.
