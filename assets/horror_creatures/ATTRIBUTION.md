# Horror creature assets

All source assets below are released under CC0 and were converted to Godot-ready GLB files for this project.

- `infected_zombie.glb`: **Mobile Ready Zombie**, OpenGameArt — https://opengameart.org/content/mobile-ready-zombie
- `horror_runner.glb`: **3D Horror Game Monster**, OpenGameArt — https://opengameart.org/content/3d-horror-game-monster
- `plague_hound.glb`: **Evil Giant Rat**, OpenGameArt/LPC — https://lpc.opengameart.org/content/evil-giant-rat

The quadruped source was cleaned before export to remove the original demonstration plane, lights, camera, and oversized auxiliary hair object.
